# 私立医学部 受験カレンダー 2027

2027年1月〜3月の私立医学部入試日程を表示する、スマートフォン対応のPWAです。

## 主な機能

- 月間カレンダーと日付別の詳細表示
- 日付タップで、その日に該当する全入試方式と一連の日程を表示
- 地域・大学別のアコーディオンから入試方式を選択
- 選択した入試方式だけをカレンダーに反映
- 31大学・51入試方式の一次試験、一次発表、二次試験、合格発表を収録
- 試験会場と備考を方式ごとに表示
- 一次試験・二次試験・合格発表の絞り込み
- 自分の予定と全体メモの端末内保存
- オフライン表示、ホーム画面への追加

## 日程データの更新

2026年10月15日、岩手医科大学、日本医科大学、東京慈恵会医科大学、東海大学、順天堂大学の未収録日程を公式資料から補完し、兵庫医科大学の発表時刻・受験条件を追記しました。更新対象と出典は [SOURCES.md](SOURCES.md) に記録しています。その他の方式は既存データを継承しています。

大学名・方式名から生成する保存キーは変更していないため、選択した方式とメモは引き続き利用できます。
