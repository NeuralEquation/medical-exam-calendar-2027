# 私立医学部 受験カレンダー 2027

2027年1月〜3月の私立医学部入試日程を表示する、スマートフォン対応のPWAです。

## 主な機能

- 月間カレンダーと日付別の詳細表示
- 日付タップで、その日に該当する全入試方式と一連の日程を表示
- 地域・大学別のアコーディオンから入試方式を選択
- 選択した入試方式だけをカレンダーに反映
- 31大学・84入試方式の共通テスト、一次試験、一次発表、二次試験、合格発表を収録
- 共通テスト利用・併用方式、個別の小論文試験、対象者限定の追加試験も表示
- 試験会場と備考を方式ごとに表示
- 一次試験・二次試験・合格発表の絞り込み
- 自分の予定と全体メモの端末内保存
- オフライン表示、ホーム画面への追加

## 日程データの更新

2026年10月15日、既存の51方式から84方式へ拡充しました。久留米大学の新設共通テスト利用A・B日程、北里大学の共通テスト利用前期・後期、東北医科薬科大学の共通テスト利用、各大学の共通テスト利用・併用方式などを追加しています。確認範囲と公式出典は [SOURCES.md](SOURCES.md) に記録しています。

大学名・方式名から生成する保存キーを維持しています。産業医科大学の従来の「一般A・B」だけはA・Bに分け、旧方式の選択・メモを両方へ引き継ぎます。

表示範囲は2027年1月〜3月の医学科入試です。共通テストの必要科目、受験日選択、地域枠や総合型選抜の出願条件は各方式の公式要項を確認してください。

確認コマンド：`node --test tests/admissions.test.cjs`
